# Ceylon Authentic Store

A Java Servlet and JSP based web application developed using the MVC architecture.

## Features
- Browse Sri Lankan authentic products
- Place product orders
- Product categories:
  - Tea
  - Spices
  - Batik
  - Handicrafts
  - Ayurvedic Products

## Technologies Used
- Java
- JSP
- Servlets
- HTML
- CSS
- Apache Tomcat 9
- Eclipse IDE
